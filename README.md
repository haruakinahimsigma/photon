# LIMINAL

An interactive mathematical environment rendered entirely in WebGL 2 and GLSL ES 3.00.

LIMINAL explores the Mandelbulb: a three-dimensional fractal generated by iterating a nonlinear equation in spherical coordinates. The scene is ray-marched in a fragment shader, with procedural lighting, soft shadows, ambient occlusion, reflective highlights, palette controls and a procedural starfield.

## Run locally

Requires a browser with WebGL 2 and Node.js.

```bash
npm start
```

Open http://localhost:3000.

## Controls

- Drag to rotate the camera
- Scroll to dolly
- Space to pause/resume automatic orbit
- H to hide/show the control panel
- Adjust fractal power, iteration depth, camera distance and luminance
- Switch between four color fields

## Deploy

The project is a static WebGL experience served by a minimal Node HTTP server. Railway can deploy it directly from this repository using the start command `npm start`.

## Rendering

- WebGL 2 / GLSL ES 3.00
- Mandelbulb distance estimator
- Sphere-traced ray marching
- Finite-difference surface normals
- Soft shadow approximation and ambient occlusion
- Procedural starfield and color fields

The renderer is an artistic real-time fractal visualization, not a physically based simulation.
